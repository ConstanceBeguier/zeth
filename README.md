# Zeth

Zeth is a privacy-preserving protocol built on Ethereum that enables private token transfers using zero-knowledge proofs (ZKPs) and cryptographic commitments.

## Disclaimer

**⚠️ Warning: Experimental Software**

Zeth is an experimental academic project developed for educational and research purposes.

The protocol and its smart contracts have **not been audited** and may contain bugs, vulnerabilities, or security flaws that could result in the loss of funds.

**Do not use Zeth in production or with real assets.** Use it at your own risk.
